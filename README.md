# Chai Sutta Adda

A tapri-style YouTube playlist microsite inspired by communal radio/player pages.

Replace `PL_TAPRI_PLAYLIST_ID` in `app/page.tsx` with the real YouTube playlist
id when the playlist is ready. The page uses that value for both the embedded
player and the playlist button.

## Local preview

```bash
pnpm install
pnpm run dev
```

## Validation

```bash
pnpm test
```
